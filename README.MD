### projects

#### hybrid repo syncer

[a lightweight CLI tool](https://github.com/miv403/hybrid-repo-syncer) to map and sync the directories across repos. it simplifies multi-repository code synchronizazation with respected commit history.

#### AGV Pathfinder

[optimization project](https://github.com/miv403/agv-pathfinder) about [Cooperative A*](https://ojs.aaai.org/index.php/AIIDE/article/view/18726) (*CA\**) based [Multi-Agent Pathfinding](https://en.wikipedia.org/wiki/Multi-agent_pathfinding) (*MAPF*) simulation for one way corridor and dynamic task cases.

#### C/C++ FCNN Framework

i have developed a [fully connected neural network framework](https://github.com/miv403/fully-connected-neural-network) with C++ and qt5. it has functionalities like 2D space classifier and regressor. also i have used same framework to develop MNIST Database [digit recognizer](https://github.com/miv403/digit-recognition-fcnn).

#### MPU9250 Sensor Fusion and Attitude Indicator

this is a [project to calibrate and fuse MPU9250 with ESP32](https://github.com/miv403/esp32-mpu9250).

#### Lidar Visualizer

simple point cloud [visualizer for LD19 Lidar](https://github.com/miv403/lidar-visualizer).

#### STG Live Messenger

[local instant messagging application](https://github.com/miv403/stg-live-messenger) that implements steganography and DES encryption with client-server pattern. it uses [LSB](https://en.wikipedia.org/wiki/Bit_numbering#Bit_significance_and_indexing) [steganography](https://en.wikipedia.org/wiki/Steganography) to embed password hash to profile picture of user. also messages are encrypted with [DES](https://en.wikipedia.org/wiki/Data_Encryption_Standard) on [CBC](https://en.wikipedia.org/wiki/Block_cipher_mode_of_operation#CBC).
